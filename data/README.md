# Dataset BodyM

Este proyecto utiliza el **Body Measurements Dataset (BodyM)**.

Debido a restricciones de tamaño (25Mb), el dataset completo no se incluye en este repositorio.

## Descripción
- Más de 8000 siluetas humanas frontales y laterales
- Más de 2500 sujetos reales
- 14 medidas corporales continuas
